# Typography

- **Plus Jakarta Sans Bold**: headings and the Campusbite wordmark. Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans).
- **Inter Regular, Medium, Semibold and Bold**: body text, navigation, forms, prices and pickup codes. Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).

Both families use the SIL Open Font License 1.1. Full notices are included in `Inter-OFL.txt` and `PlusJakartaSans-OFL.txt`.

The font files are loaded from individual `@expo-google-fonts` weight modules in `src/app/_layout.tsx`, using Expo Font. They are bundled with the app and do not require a Google Fonts network request at runtime.
