# Typography

- **Plus Jakarta Sans Bold**: headings and the Campusbite wordmark. Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans).
- **Inter Regular, Medium, Semibold and Bold**: body text, navigation, forms, prices and pickup codes. Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter).
- **Instrument Serif Italic**: the Home hero's “Better breaks.” line. Copyright 2022 The Instrument Serif Project Authors (https://github.com/Instrument/instrument-serif).

All three families use the SIL Open Font License 1.1. Full notices are included in `Inter-OFL.txt`, `PlusJakartaSans-OFL.txt` and `InstrumentSerif-OFL.txt`.

Inter and Plus Jakarta Sans are loaded from individual `@expo-google-fonts` weight modules in `src/app/_layout.tsx`, using Expo Font. Instrument Serif is loaded from its local TTF. All fonts are bundled with the app.
